The Hux Blog theme is a legendary Jekyll layout known for its clean, distraction-free aesthetic and stunning typography.

By adapting it into React with **Tailwind CSS**, you get the modern SPA feel and lightning-fast transitions while preserving the beautiful font pairings (`Lora` and `Open Sans`) that made the original so beloved.

### The Beauty of Markdown

Using the integrated `react-markdown` library paired with `remark-gfm`, your posts comfortably support:

- **Bold** and *Italic* text
- Code Blocks and Syntax highlighiting
- Tables and Checklists
